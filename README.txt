CARA DAPAT APK:
1. Buat repo baru di github.com, upload SEMUA isi folder ini (termasuk folder .github).
2. Tab Actions -> tunggu "Build APK" selesai -> Artifacts -> ARPalsu-APK -> download, unzip, install app-debug.apk.

CARA PAKAI:
- Izinkan kamera. Arahkan HP ke lantai, ketuk layar untuk menaruh karakter.
- Joystick kiri bawah untuk menggerakkan karakter (maju = arah hadap kamera).
- "Reset arah" kalau arah melenceng. "Tinggi HP" atur sesuai tinggi HP dari lantai (default 1,3 m).
- Hanya rotasi HP yang dilacak, bukan posisi: kalau kamu berjalan, objek ikut bergeser.
